计算口径与数据边界

持币人收入代理采用 DefiLlama dailyHoldersRevenue（Perps + Spot，适配器亦包含 AQAv2 收益及 HIP-1 拍卖销毁价值），不是总手续费、已核实实际回购或会计净利润。全解锁情景固定使用原档案 955,307,079.4341414 HYPE（2026-10-07 供应快照），不会随新 API 当前供应改写历史；不是历史实际供应、未来最终供应或 10 亿最大供应 FDV。

R30(D) = D−29 至 D 的每日收入合计；年化分母 = R30 × 365/30；流通倍数 = 流通市值 / 年化分母。CoinGecko D+1 00:00 UTC 的精确同时间戳价格和市值归到 D，作为近似收盘；非午夜即时点不使用。30 日缺任何一天即 NA，真实零保留，零分母不输出倍数。

固化历史截至 2026-10-06，来自 2026-10-07 归档。固化记录和已缓存的有效原始输入不被新 API 历史修订覆盖。打开页面按设备系统日期尝试补到 UTC 昨日；系统时间不可信，请自行核对。上游延迟、CORS、限流和网络失败均可能使补齐失败，不保证打开即可取得最新数据。

增量仅保存在本浏览器 localStorage，不同步其他设备、不写回服务器；清除浏览器数据即丢失增量。公共行情接口仅覆盖最近365天，长时间未访问或换设备可能留下无法自动补齐的历史缺口。UNI 累计供应对此尤其敏感。浏览器缓存可被本机修改，不是可审计的永久档案。

图例可切换曲线，左右坐标轴独立，交点不代表相等。卡片显示最近有效流通估值日的同日数据，并明确标注实际日期，不冒充目标日；目标日期、待补齐原因独立显示，表格保留断档。仅供研究，不是投资建议。
